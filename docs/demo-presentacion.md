# Presentar la beta de DoorManager Pro

Enlace público: https://demo-doormanager-pro.enamarquezf.workers.dev/

## Mensaje listo para compartir

Prueba DoorManager Pro: del aviso del cliente al trabajo técnico y la gestión de la empresa. Esta beta muestra una parte de DMP con datos ficticios y una guía visual. Puedes entrar sin correo ni contraseña y elegir Técnico, SAT, Oficina, Comercial o Gerencia.

Entra aquí: https://demo-doormanager-pro.enamarquezf.workers.dev/

Para una primera visita elige «Descubrir DMP». Para seguir tu propio caso elige «Crear mi propio recorrido». Cada visitante tiene una empresa temporal independiente. Usa siempre datos inventados.

## Preparar una demostración

1. Comprueba «Buscar actualizaciones» antes de presentar y guarda los formularios antes de actualizar.
2. Abre una sesión nueva; la demo conserva los datos solo durante la prueba.
3. En la visita breve, termina un check para seguir a Oficina. Oficina muestra otro caso preparado; no es una factura creada por el check que acabas de rellenar.
4. Para mostrar un caso de principio a fin, usa el recorrido completo SAT → Técnico → SAT → Oficina → Gerencia.
5. Al enseñar compras, prepara la factura desde el pedido para copiar artículos y cantidades. Revisa antes de registrar y después anota un pago ficticio. La demo no realiza cargos bancarios.
6. Las fotos del equipo y los documentos de muestra son ficticios. No subas información personal o de clientes.

Contacto de demostraciones: enamarquezf@gmail.com.

## Alcance

Es una beta para probar y recoger comentarios. La comprobación de recorridos guiados no equivale a certificar todas las opciones ni el uso con datos reales. El estado y las pruebas pendientes se documentan en demo-audit-guided-journeys.md.
